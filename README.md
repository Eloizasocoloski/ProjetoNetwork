Projeto Network

Este projeto em C# simula uma rede de elementos conectados entre si.
A implementação permite criar e remover conexões entre elementos, além de consultar se existe ligação entre eles e identificar o nível de conexão entre os elementos pesquisados.

Instalação e como usar:

git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
dotnet run
